local_dataset_io¶

Local dataset I/O helpers for JSONL, TSV and TREC-in-GZIP parsing.

This module provides thin file readers and writers used by the dataset parsing notebook. Parsers are intentionally lightweight and optimized for predictable, line-oriented input files in this repository.

pylib.local_dataset_io.load_jsonl(path: Path) → List[Dict[str, Any]]¶

Load a UTF-8 JSONL file into a list of dictionaries.

Empty lines are ignored. Each non-empty line must contain exactly one valid JSON object. If split files like .part2 or .part3 exist for the same base name, they are loaded in numeric order after the base file.

Parameters:

path – Path of the base JSONL file, e.g. Path("docs.normalized.jsonl").

Returns:

base file first, then the part files by part number.

Return type:

Parsed records in file order

Raises:

  • FileNotFoundError – If the base file does not exist.

  • json.JSONDecodeError – If a line is not valid JSON.

pylib.local_dataset_io.parse_trec_corpus(path: Path) → Tuple[List[Dict[str, Any]], Dict[str, Any]]¶

Parse a gzip-compressed, line-oriented TREC-like corpus file.

Expected structure is tag-delimited documents with <DOC>, <DOCNO>, <TEXT...> and closing tags, usually one tag per line; a combined </DOC><DOC> line is treated as two tags. The parser is intentionally permissive and tracks structural differences in the returned stats dictionary.

Limitations: this is not a full XML parser; nested tags and inline multi-tag constructs outside the expected line-oriented pattern may be ignored or flattened. Undecodable bytes are dropped.

Parameters:

path – Path of the .trec.gz corpus file.

Returns:

Tuple (docs, stats). docs holds one {"docno": str, "text": str} per document that has a <DOCNO>. stats counts physical lines, tags, parsed documents, documents without DOCNO or text, and the differences between tag counts (parser_diff_*).

Raises:

  • FileNotFoundError – If the file does not exist.

  • OSError – If the gzip stream cannot be opened or decoded.

pylib.local_dataset_io.parse_tsv(path: Path) → List[Dict[str, Any]]¶

Parse a UTF-8 TSV file with a header row.

The parser uses csv.DictReader and returns one dictionary per data line. Header names are taken from the first row and values remain untyped strings.

Parameters:

path – Path of the tab-separated values file.

Returns:

One dictionary per data line, keyed by the header names, e.g. [{"query-id": "1", "corpus-id": "d1", "score": "1"}].

Raises:

FileNotFoundError – If the file does not exist.

pylib.local_dataset_io.write_jsonl(path: Path, records: Iterable[Dict[str, Any]]) → int¶

Write records as ASCII-safe JSONL and return the number of written rows.

The parent directory is created automatically when missing. Non-ASCII characters are escaped because ensure_ascii=True is used. Once a file reaches JSONL_SPLIT_THRESHOLD rows, additional rows continue in .part2, .part3 and so on.

Existing .part* files of the same base name are deleted first so that no stale parts remain.

Parameters:

  • path – Target JSONL file path, e.g. Path("output/docs.normalized.jsonl").

  • records – JSON-serializable dictionaries, written one per line in iteration order.

Returns:

Number of written records.

Raises:

TypeError – If a record is not JSON serializable.

dataset_normalization¶

Normalization helpers for retrieval dataset roles.

The functions in this module map heterogeneous raw records into a shared structure with queries, docs and qrels records and provide simple consistency checks used in notebook-based preprocessing.

Compute basic ID consistency diagnostics across normalized roles.

The check compares query and document IDs referenced by qrels against the available normalized query and document sets.

Parameters:

  • queries – Normalized query records with query_id.

  • docs – Normalized document records with doc_id.

Remove duplicate normalized records by role-specific identity keys.

Deduplication keeps the first occurrence order per role. Identity keys are query_id for queries, doc_id for docs and (query_id, doc_id, relevance) for qrels. Queries and docs with an empty or missing ID are dropped.

Parameters:

Returns:

New mapping with the keys queries, docs and qrels (missing roles become empty lists), duplicates removed.

significance¶

Paired significance tools following docs/evaluation_protocol.md (cluster level).

Estimators: cluster sign-flip test with one sign per gold-document cluster, ratio-estimator cluster bootstrap and Holm correction. Every call creates its own numpy.random.default_rng(seed) so results do not depend on call order.

pylib.significance.cluster_bootstrap_ci(differences: ndarray, cluster_indices: ndarray, n_clusters: int, cluster_sizes: ndarray, seed: int = 42, n_resamples: int = 10000) → list[float]¶

Compute the 95% percentile CI of the mean difference under cluster resampling.

Clusters are resampled with replacement (multinomial counts); each resample’s estimate is the ratio of the resampled difference sum to the resampled number of queries, so the mean stays query-weighted. A fresh default_rng(seed) is created on every call.

Parameters:

  • differences – Per-query score differences, shape (n_queries,).

  • cluster_indices – Cluster index per query, same order as differences.

  • n_clusters – Number of clusters (see make_clusters()).

  • cluster_sizes – Number of queries per cluster, shape (n_clusters,).

  • seed – Seed of the random generator.

  • n_resamples – Number of bootstrap resamples.

Returns:

[lower, upper] bounds (2.5th and 97.5th percentile) of the resampled estimates.

pylib.significance.cluster_sign_flip(differences: ndarray, cluster_indices: ndarray, n_clusters: int, seed: int = 42, n_permutations: int = 100000) → dict¶

Run a two-sided paired sign-flip test with one random sign per cluster.

The test statistic is the absolute mean difference. Each cluster contributes its summed difference, and the sign of the whole cluster is flipped at random. If at most EXACT_MAX_N clusters have a non-zero sum, all 2^m sign patterns over these m clusters are enumerated (p = hits / 2^m). Otherwise signs are drawn Monte-Carlo style over all clusters with a fresh default_rng(seed) (p = (hits + 1) / (n_permutations + 1)).

Parameters:

  • differences – Per-query score differences between two retrievers, shape (n_queries,).

  • cluster_indices – Cluster index per query, same order as differences.

  • n_clusters – Number of clusters (see make_clusters()).

  • seed – Seed of the Monte-Carlo random generator; unused for exact enumeration.

  • n_permutations – Number of Monte-Carlo sign patterns, drawn in blocks of 10,000 plus one smaller remainder block, so exactly this many patterns are drawn.

Returns:

Dict with p, method (“exact” | “monte_carlo”), n_nonzero (clusters with sum != 0) and mc_floor (True if a Monte-Carlo p sits at the floor 1 / (n_permutations + 1), i.e. is only an upper bound).

german_text¶

German text preprocessing for lexical retrieval (lowercase, tokenization, stopwords, Snowball stemming).

Components: regex tokenizer tokenize_de (shared with the standard BM25 run scripts/run_bm25.py), the German stopword list of stopwordsiso (pip, version pinned via importlib.metadata, 620 entries), and the Snowball German stemmer of snowballstemmer (the reference implementation used by nltk’s SnowballStemmer('german')). Compound splitting is intentionally omitted: no reviewed decompounding library is available offline/via pip in this environment (german-compound-splitter not installable; CharSplit is an unreviewed statistical splitter).

pylib.german_text.german_stopwords() → frozenset[str]¶

Return the lowercase German stopword set of stopwordsiso.

The content is fixed by the installed package version (see preprocessing_info()). The set is built once and cached.

pylib.german_text.preprocess_de(text: str | None, remove_stopwords: bool = True, apply_stemming: bool = True) → list[str]¶

Turn German text into index terms for lexical retrieval.

Steps in order: lowercase, regex tokenization (letters incl. umlauts/ß and digits), removal of stopwords (matched on the unstemmed lowercase token), Snowball German stemming.

Parameters:

  • text – Raw text; None is treated as empty.

  • remove_stopwords – Drop tokens that are German stopwords if True.

  • apply_stemming – Apply the Snowball stemmer to the remaining tokens if True.

Returns:

List of terms in text order (duplicates kept for term-frequency weighting).
